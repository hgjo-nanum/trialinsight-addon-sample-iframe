1. 우리가 iframe 높이를 직접 바꿔볼 수 있나? (전부 실패합니다)

아래 버튼은 자식 화면에서 iframe 크기를 스스로 키우려는 시도들입니다. 실제 브라우저 반응을 그대로 찍습니다.

버튼을 눌러보세요.

2. 되는 방법 — 부모에게 "통보"하기

우리가 할 수 있는 건 postMessage 로 필요한 높이를 알려주는 것까지입니다. 실제로 iframe.style.height 를 실행하는 주체는 부모(myTrial)입니다.

부모 화면에서 “TI_HEIGHT 무시” 를 켠 채 눌러보세요. 우리가 아무리 정확히 보내도 iframe 은 꿈쩍하지 않습니다. 높이의 결정권이 우리에게 없다는 뜻입니다.

3. auto / fill 차이

부모가 보내는 TI_MODE 를 받아 우리가 전환합니다. 부모 화면의 auto/fill 버튼을 눌러 비교해 보세요.

fill — 내부 스크롤 있음. 주어진 창에 콘텐츠를 접어 넣음. 높이 통보 안 함.
auto — 내부 스크롤 없음. 콘텐츠 전체 높이를 통보하고 부모가 iframe 을 늘려줌.
auto 인데 부모가 안 늘려주면 → 스크롤이 없으므로 하단이 잘려서 접근 불가. 그래서 안전망이 필요.

4. 안전망 (fill 자동 복귀)

보낸 높이를 부모가 반영했는지는 window.innerHeight 로 확인할 수 있습니다(내 창 정보라 읽기는 가능). 어긋나면 내부 스크롤을 되살려 콘텐츠가 잘리지 않게 합니다.
