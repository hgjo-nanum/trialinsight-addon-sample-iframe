📊 TrialInsight Addon

이 페이지는 다른 도메인(GitHub Pages)에서 로드되어 myTrial 호스트 안에 iframe으로 삽입됩니다. 호스트의 세션/쿠키에 직접 접근할 수 없으며, postMessage 핸드셰이크로만 컨텍스트를 받습니다.

통합 진단 (Integration Diagnostics)

대기
① 호스트 세션 직접 접근
다른 도메인이라 parent의 sessionStorage/쿠키 직접 접근은 차단되어야 정상.
대기
② 호스트에 READY 핑 전송
iframe이 준비되었음을 부모에 알림.
대기
③ postMessage 세션 컨텍스트 수신
origin 검증 후 projectId / userId / bearer 토큰 수신.
대기
④ bearer 토큰으로 CORS API 호출
쿠키 없이 Authorization 헤더로 인증 데이터 획득.
